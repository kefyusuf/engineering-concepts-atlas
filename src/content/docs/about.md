title: About this project
description: Scope, editorial standards and release criteria for the Engineering Concepts Atlas.
---

Engineering Concepts Atlas is a language-agnostic engineering reference. The initial editorial catalog contains **100 candidates across 20 categories and 6 groups**. Candidate terms are not synonymous with verified documentation.

## Editorial integrity

- Articles must state assumptions, scope, guarantees and failure conditions.
- Sources must support the **specific claim**, not merely the broad topic.
- Standards drafts must be identified as drafts. Vendor guarantees must be version-scoped.
- Code samples should be executable or explicitly labelled as pseudocode.
- Review metadata is attached only after a real technical/editorial review.

## Current release state

This is an implementation preview. Fifteen concept pages are drafts pending independent sign-off. A separate `build:release` command intentionally blocks production publication until twenty articles, one per category, are reviewed and approved.
